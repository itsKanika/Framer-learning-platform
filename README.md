# Skillpath

Skillpath is a modern learning marketplace landing page designed to help users discover practical online courses.

## ✨ Features

- Responsive and modern UI
- Course discovery and search
- Course sorting by price
- Dynamic course cards
- Multi-currency support
- Refundable course indicators
- Loading, error, and empty states
- Cute, friendly learning-focused visual design

## 🛠️ Built With

- Framer
- React / TypeScript
- API-based course data
- Responsive CSS

## 🎯 Goal

The goal of Skillpath is to create a simple and engaging platform where learners can quickly discover courses and find skills that match their interests.

## 🚀 Project

Designed and developed as part of a frontend assignment, with a focus on clean UI, usability, responsiveness, and real API-driven content.
